# CS480A7-Project

## Local Setup
First export your github token as a enviroment variable
run main.py
run clean.py
run independent.py
run derived.py

## Ssh'd to lab machine setup
- in project root run pip install python-dotenv
- create a file named ".env" in the project folder
- add the line GITHUB_TOKEN = your_github_token_here to it

## Cleaning the data
works on python 
run "python clean.py"

## Adding independent Variables
works on python 3.14.3
run "python independent.py"

## Derived Variables
works on python 3.9.25
run "python derived.py"
